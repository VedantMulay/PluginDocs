# Developer API

Email Linker has a small developer API for events. All the classes are located in `me.comphack.emaillinker.api.events`

| Event | Description |
|-------|-------------|
| `EmailLinkAttempt` | When a user attempts to link his email address |
| `EmailLinkSuccess` | When a user successfully links his email address |
| `EmailResendEvent` | When the verification code is resent to the user |
