# Waypoint Plugin
Plugin helps you to configure waypoints for your players and show them proper direction to reach a location.

:::warning 
This documentation is work in progress.
:::

# Requirements
- Java v17+ 
# Installation
1. Download the plugin from [modrinth](https://modrinth.com/plugin/waypoint-plugin)
2. Put the plugin .jar file in the `plugins` folder.
3. Start your server

The plugin currently supports Bukkit, Spigot, Paper, Purpur and other forks of spigot.

More compatibility support has been planned for the future for Fabric and Sponge.
