# Player Commands


## General Commands
| Command | Info | Permission | Alias
| --- | --- | --- | --- |
| `/neptunecore` | Prints the info about the plugin | `NONE` | `/neptune` |
| `/lobby` | Sends the player back to lobby servers | `NONE` | `/hub` |
| `/onlinestaff` | Shows the usernames of online staff on the server | `NONE` | `/staff` |
| `/message <player> <message>` | Sends a message a online player on the network | `NONE` | `/msg` |
| `/reply <message>` | Sends a message to the last person messaged | `NONE` | `/r` |


## Friends Commands
| Command | Info | Permission |
| --- | --- | --- |
|`/friend add <Player>`| Add a player as a friend | `NONE`|
|`/friend remove <Player>`| Remove a player as a friend | `NONE`|
|`/friend accept <Player>`| Accept a player's friend request | `NONE`|
|`/friend deny <Player>`| Deny a player's friend request | `NONE`|
|`/friend list`| List your friends | `NONE`|
|`/friend requests`| See friend requests you have received | `NONE`|
