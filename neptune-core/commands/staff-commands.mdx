# Staff Commands

| Command | Info | Permission |
--- | --- | --- |
| `/staffchat` | Toggles staff chat | `neptune.staff` |
| `/adminchat` | Toggles admin chat | `neptune.admin.chat` |
| `/commandsspy` | Toggles command spy | `neptune.staff.commandspy` |
| `/socialspy` | Toggles social spy | `neptune.staff.socialspy` |
| `/maintenance <on:off>` | Toggle server maintenance | `neptune.staff.maintenance` |
